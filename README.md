# LED Toggle Using Bare-Metal Programming

A basic embedded systems project demonstrating **LED toggling using bare-metal programming** without relying on high-level libraries or HAL frameworks. The project directly configures and accesses the microcontroller's hardware registers to control an LED through GPIO.

### Key Features

* Direct GPIO register configuration
* LED ON/OFF control using bare-metal Embedded C
* No HAL or high-level peripheral libraries
* Demonstrates GPIO initialization and digital output control
* Provides a foundation for understanding low-level microcontroller programming

### Technologies Used

* Embedded C
* Bare-Metal Programming
* GPIO
* Microcontroller Registers
* STM32 

### Learning Outcomes

This project helps understand how microcontrollers interact with hardware at the register level and provides practical experience with **GPIO configuration, memory-mapped registers, bit manipulation, and low-level embedded programming**.
